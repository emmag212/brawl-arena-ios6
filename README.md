# Brawl Arena (iOS 6)

Оригинальный top-down арена-броулер в механике Brawl Stars 2018, собранный специально под iPhone 4s на iOS 6.1.3: HTML5-канвас, чистый ES5, без зависимостей. Не связан с Supercell: персонажи, графика и название — собственные; воспроизводится игровая механика (не защищается авторским правом), а не ассеты игры Supercell.

## Режим

**Захват гемов, 3 на 3** против ботов: из центра арены выходят гемы, соберите 10 на команду и продержитесь 15 секунд. Погибший роняет все свои гемы. Кусты прячут бойца, стены блокируют выстрелы, здоровье восстанавливается через 3 секунды вне боя.

## Управление

- **Левая половина экрана** — движение (виртуальный стик).
- **Правая половина** — прицел: тянуть и отпустить = выстрел; лёгкий тап = выстрел вперёд.
- На ПК для отладки: WASD/стрелки, мышь прицеливается, зажатая кнопка стреляет.

## Запуск

Локально:

```
node server.js
# → http://localhost:8123
```

На iPhone 4s (iOS 6.1.3): ПК и iPhone в одной Wi-Fi сети → в Safari открыть адрес из вывода `server.js` (например `http://192.168.x.x:8123`) → «На экран “Домой”» — игра запустится в полный экран без адресной строки. Джейлбрейк не обязателен: это веб-приложение.

Цель производительности: стабильные 30 Гц логики (фиксированный шаг) на A5 — рендер 480×320 растягивается на весь экран, тайлы арены пререндерены в офскрин-канвас, в кадре минимум вызовов отрисовки.

## Структура

- `js/core.js` — константы и утилиты
- `js/arena.js` — карта, коллизии, линия видимости, пререндер тайлов
- `js/battle.js` — бойцы, пули, гемы, боты
- `js/main.js` — цикл, ввод, камера, HUD
- `server.js` — статический сервер для локальной сети
- `docs/roadmap.md` — план разработки

## Ограничения iOS 6, учтённые в коде

- Только ES5: без let/const, стрелочных функций, промисов, шаблонных строк.
- `ctx.ellipse` отсутствует — тени рисуются масштабированной дугой.
- Touch-события вместо pointer-событий; `preventDefault` против скролла и зума.
- Без WebAudio-ассетов пока: звук — в дорожной карте.
